# ViralMovie API — Vercel Ready

Important: deploy the CONTENTS of this ZIP as the repository root.
The `lib/` folder must be at the same level as `app/` and `package.json`.

Required source files:
- lib/store.ts
- lib/plans.ts

Do not upload the ZIP itself as a nested folder in the repository.

Environment variables are configured in Vercel Project Settings > Environment Variables.
